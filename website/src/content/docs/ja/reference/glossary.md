## 編集の用語

### アセット（素材）
`montash import` で取り込んだ元のメディアファイル（映像・音声・画像・字幕・テキスト）。
ID はファイル名から作られます（`clip_a.mp4` → `clip_a`）。
**montash がアセットのファイルを書き換えることはありません。**

### トラック
クリップを載せる層。映像 `V1`, `V2`...、音声 `A1`, `A2`...、テキスト `T1`... の 3 種類があります。
映像トラックは番号が大きいほど上に合成されます。

### クリップ
トラックに置かれた「アセットの一部」。ID は `c1`, `c2`... です。
どのアセットの `in_f` 〜 `out_f` を、タイムラインの `start_f` に置くか、という情報を持ちます。

映像に音声がある素材を置くと、映像クリップと音声クリップが **リンクされた 2 つのクリップ**として作られます。
片方を動かすともう片方も付いてきます。`--unlink` で切り離せます。

### のりしろ（handle）
クリップとして使っている範囲の**外側に残っている素材**。
トランジションはこののりしろを使って 2 つの映像を重ねます。
のりしろが足りないと `E_INSUFFICIENT_HANDLE` になります。

### リップル（ripple）
ある編集の結果を、**後続の要素にも反映させる**こと。
クリップを 1 秒短くしたとき、リップルすれば後続が 1 秒手前に詰まり、隙間が残りません。

- `--ripple` / `--ripple=all` … すべてのトラックの後続要素（BGM・テロップも動く）
- `--ripple=track` … そのトラックの後続要素だけ

### ギャップ
映像が何も無い区間。リップルせずにトリムや削除をすると生まれます（`W_GAP_CREATED`）。
`montash timeline gaps` で一覧できます。

### テロップ（テキストクリップ）
テキストトラックに置かれた文字。ID は `x1`, `x2`... です。
本文とスタイル（フォント・サイズ・色・位置）を持ちます。

### 字幕
外部の SRT / VTT / ASS ファイルをタイムラインに付けたもの。ID は `s1`, `s2`... です。
`burn`（映像に焼き込む）と `soft`（選択可能なトラックとして多重化する）の 2 つの方式があります。

### トランジション
隣り合う 2 クリップの繋ぎ目に入れる効果。ID は `t1`, `t2`... です。
ffmpeg の `xfade` フィルタで実現されます。

### ダッキング
あるトラックが鳴っている間だけ、別のトラックの音量を下げること。
「声が出ている間は BGM を下げる」に使います。ID は `d1`, `d2`... です。

### プロキシ
素材から作られる、軽い H.264/AAC のコピー。ブラウザでのプレビュー再生に使われます。
`.montash/cache/<asset_id>/proxy.mp4` に置かれ、**いつでも再生成できます**。

### プレビュー
タイムライン全体を組み立てた確認用の動画。`.montash/preview/timeline.mp4` です。
映像はセグメント単位でキャッシュされるので、変更した部分だけが作り直されます。
プロキシ画質で、ラウドネス正規化は適用されません。

## 履歴の用語

### op
状態を変えるコマンド 1 回の記録。ID は `o_0001`, `o_0002`... です。**自動で記録されます。**
実行したコマンド、変更内容、その前後の状態のスナップショットを持ちます。

### コミット（commit）
連続する op のまとまりに、人が読めるメッセージを付けたもの。ID は `k_0001`, `k_0002`... です。
`k` は kommit の頭文字で、クリップ ID の `c1` と衝突しないようにこの文字を使っています。

### pending ops
まだコミットされていない op。git の uncommitted changes に相当します。
`montash status` で一覧されます。

### HEAD
いま `project.json` に展開されている op。

### tip
ある系列の最新の op。`montash checkout tip` で戻れます。

### detached
HEAD が tip ではない状態。過去の時点を見ている状態です。
ここから編集すると新しい系列が枝分かれしますが、元の op 列は残ります。

### タグ（tag）
op またはコミットに付ける名前。`montash tag rough-cut` のように付け、
`montash checkout rough-cut` で戻れます。

### オブジェクト（object）
`project.json` のスナップショット。内容のハッシュで名前が付けられ、重複は排除されます。
git の blob に相当します。

### `~n` 記法
「n 個前」を意味します。`HEAD~3`、`k_0007~1` のように書きます。

### actor
その op を実行した主体。`ai` / `human` / `web` / `system` のいずれかです。
ブラウザからの操作は `web` として記録されます。

## 時間の用語

### フレーム表記（`f:`）
`f:45` は「45 フレーム目」という意味です。**丸めが起きない**ので、
CLI が返した値を再利用するときはこの形を使ってください。

### スナップ
秒で指定した時間を、最寄りのフレームに丸めること。丸めが起きると `W_SNAPPED` が返ります。

### 有理数 fps
フレームレートを `30000/1001` のような整数比で保持する方式。
29.97fps を小数で持つと誤差が蓄積しますが、有理数なら正確です。
